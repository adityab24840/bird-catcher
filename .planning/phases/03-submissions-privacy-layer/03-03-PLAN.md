    **Exported upload function** — `uploadSubmissionPhoto(pairId: string, entryDate: string, uid: string, file: File): Promise<string>`:

    Implementation steps in order (from D-03 of CONTEXT.md):

    Step 1 — HEIC detection:
    ```
    const isHeic =
      file.type === 'image/heic' ||
      file.type === 'image/heif' ||
      file.name.toLowerCase().endsWith('.heic') ||
      file.name.toLowerCase().endsWith('.heif')
    ```
    The filename extension fallback is mandatory — iOS sometimes sets `file.type` to `''` (empty string) for HEIC files.

    Step 2 — Conditional HEIC conversion (lazy import):
    - If `isHeic`: `const heic2any = (await import('heic2any')).default` — dynamic import keeps the ~1.2 MB WASM out of the initial bundle
    - Call `heic2any({ blob: file, toType: 'image/jpeg', quality: 0.9 })`
    - Guard return: `const jpegBlob: Blob = Array.isArray(result) ? result[0] : result` — burst/Live Photo HEIC returns `Blob[]`
    - If NOT heic: `let fileToCompress: File = file`

    Step 3 — Wrap Blob to File for browser-image-compression:
    - `const jpegFile = new File([jpegBlob], 'photo.jpg', { type: 'image/jpeg' })` — `imageCompression` requires `File`, not `Blob`

    Step 4 — Compress:
    - `const compressedFile = await imageCompression(jpegFile, { maxSizeMB: 1, maxWidthOrHeight: 1920, useWebWorker: true })`

    Step 5 — Upload to Firebase Storage:
    - `const storagePath = \`pairs/${pairId}/entries/${entryDate}/${uid}/photo.jpg\``
    - `const storageRef = ref(storage, storagePath)`
    - `const snapshot = await uploadBytes(storageRef, compressedFile, { contentType: 'image/jpeg' })`

    Step 6 — Get download URL and return:
    - `const photoURL = await getDownloadURL(snapshot.ref)`
    - `return photoURL`

    Wrap the entire function body in `try/catch` — log error with `console.error('[uploadSubmissionPhoto] failed:', err)` then re-throw so callers can display inline errors.
