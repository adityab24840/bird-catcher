## Phase Goal

**As an** authenticated user without a pair, **I want to** connect with exactly one other person using a one-time invite code, **so that** we share a private space that no third person can join, no matter what.

<objective>

After this plan, the client can call Cloud Functions and reactively observe pairId changes in real time. The UI layer (Plan 02-03) will import these to build the interaction.

Purpose: Establish the service + hook contracts so Plan 02-03 can build UI against well-defined, tested client APIs.

    Define: `interface PairState { pairId: string | null; pairLoading: boolean }`

    Export `function usePairId(uid: string | null): PairState`. Inside:
    - useState: `pairId` (null), `pairLoading` (true)
    - useEffect with uid as dependency:
      - if uid is null: setPairId(null), setPairLoading(false), return early
      - Subscribe: `onSnapshot(doc(db, 'users', uid), (snap) => { const data = snap.exists() ? (snap.data() as UserDoc) : null; setPairId(data?.pairId ?? null); setPairLoading(false) }, (err) => { console.error('[usePairId] listener error:', err); setPairLoading(false) })`
      - Return cleanup: `return () => unsub()`
    - Return `{ pairId, pairLoading }`

    This hook's real-time subscription is the mechanism that drives the D-01 route guard: when joinPair's transaction writes pairId to users/{uid}, this onSnapshot fires and App.tsx re-renders to redirect to /home.

## STRIDE Threat Register

| T-02-02-01 | Elevation of Privilege | VITE_APP_CHECK_DEBUG_TOKEN exposed in production bundle | mitigate | `.env.local` is gitignored and not included in CI/production builds. Only set VITE_APP_CHECK_DEBUG_TOKEN in .env.local — never in .env or committed config. Document in .env.example. Verify in Phase 6 bundle inspection (SEC-06). |
| T-02-02-02 | Denial of Service | App Check token refresh failure causing callable 403 errors | accept | Firebase SDK auto-retries token refresh with backoff. Emulator does not enforce App Check. Production enforcement mitigated by ReCaptchaV3Provider isTokenAutoRefreshEnabled: true. |
